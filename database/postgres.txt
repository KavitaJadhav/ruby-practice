Triggers
- Trigger is also one special function.
 This special function is called automatically whenever an insert, update, and delete events occur. These are user-defined triggers.
 PostgreSQL gives two main triggers: row and statement-level triggers.

Index

Backup in PostgreSQL
PostgreSQL database allows users to take backup using a utility.
 It contains the pg_dump utility to analyze backing up a separate database.
 This command is fired as a user with reading permissions.
 The backup utility comes under the database administrator command.
