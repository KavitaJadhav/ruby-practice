Backup in MySQL
In a MySQL database, if you use the backup utility then the data is derived as SQL statements.
 Hence, backing up and restoring large data can take a huge time because of the performance of various SQL statements.
  Moreover, to bypass inequality, MySQL secures the database throughout the backup method.
  Still, database administrators can revoke this by applying the mysqldump utility using a particular flag “:–single-transaction”.
