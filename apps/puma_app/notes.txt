.ru extension - rack up

Command to run app:
puma - Run Puma server directly.
rackup - rack runs puma server

How rack works:
- flow - browser_request -> nginx -> puma -> app (rack comes in-between of puma and app)
- app frameworks(ruby, rails, sinatra)
- app servers(puma, unicorn, webrick)
- app can be run with any the app server. app servers need to know entrypoint of the app. app need to know conventions/configurations of the server
- rack comes between app and app servers, app and app servers doesn't need to know about each others. rack will take care of that.
